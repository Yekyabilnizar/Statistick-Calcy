FAQ

{{ 'Frequently asked questions' if en else 'Pertanyaan umum' }}

{% if en %}
Is my data stored?

No. Data is processed in memory only while the calculation runs to produce the result, then discarded. See the Privacy Policy.

What data format is needed?

One row = one observation, one column = one variable, and the first row holds the column names. Use a point or comma as the decimal separator. Every method provides sample data so you can see the format.

How do I read **, *, and ns?

** = highly significant (P < 0.01), * = significant (P < 0.05), ns = not significant. The significance level α can be chosen in each analysis.

My result differs from other software

Check the type of sums of squares (here sequential Type I on balanced data), the reference category for dummy variables, and the estimation method. On balanced data ANOVA results are usually the same; verification is still recommended for publication.

{% else %}
Apakah data saya disimpan?

Tidak. Data hanya diproses di memori selama perhitungan berlangsung untuk menghasilkan hasil, lalu dibuang. Lihat Kebijakan Privasi.

Format data seperti apa yang dibutuhkan?

Satu baris = satu pengamatan, satu kolom = satu variabel, dan baris pertama berisi nama kolom. Gunakan titik atau koma sebagai desimal. Setiap metode menyediakan data contoh untuk melihat formatnya.

Bagaimana membaca tanda **, *, dan tn?

** = sangat nyata (P < 0,01), * = nyata (P < 0,05), tn = tidak nyata. Taraf nyata α dapat dipilih pada tiap analisis.

Hasil saya berbeda dengan software lain

Periksa jenis jumlah kuadrat (di sini Tipe I sekuensial pada data seimbang), kategori referensi pada variabel dummy, dan metode penaksiran. Pada data seimbang hasil ANOVA umumnya sama; verifikasi tetap dianjurkan untuk publikasi.

{% endif %}
