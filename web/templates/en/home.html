Frequently asked questions

Is my data stored?

No. Data is only processed in memory while the calculation runs, then discarded. See the Privacy Policy.

What data format is needed?

One row = one observation, one column = one variable, and the first row holds column names. Use a dot or comma as the decimal mark. Every method provides sample data so you can see the format.

How do I read the marks **, *, and ns?

** = highly significant (P < 0.01), * = significant (P < 0.05), ns (shown as “tn”) = not significant. The significance level α can be chosen in each analysis.

My results differ from other software

Check the type of sum of squares (here sequential Type I on balanced data), the reference category for dummy variables, and the estimation method. On balanced data ANOVA results are usually the same; verification is still recommended for publication.
